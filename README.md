# Minimalist CV with Astro

This is a minimalist résumé (CV) project built with [Astro](https://astro.build/), inspired by the design of developer Bartosz Jarocki and Midudev. It focuses on simplicity, and a clean presentation of professional information.

## 🧠 Features

- ✨ Clean and professional design  
- 📱 Fully responsive layout
- 🗂 Powered by [JSON Resume](https://jsonresume.org/) — content is structured and managed through a JSON file  
- 🛠 Generate a brand new CV by simply editing a single `cv.json` file — no need to touch the layout or components  

## 🚀 Tech Stack

- [Astro](https://astro.build/)  
- HTML5 + CSS3  
- [TypeScript](https://www.typescriptlang.org/)
